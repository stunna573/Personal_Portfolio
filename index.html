A little about me

Curious by nature.
Developer by choice.

I'm Kelvin Gordian, a full-stack web developer with a passion for technology and continuous learning. I enjoy turning ideas into responsive, interactive and accessible websites using modern web technologies.

My journey into software development started with curiosity about how websites work, and it has grown into a commitment to building solutions that solve real-world problems. I work with technologies such as HTML, CSS, JavaScript, React, Node.js, Python, Django and SQL, with a focus on functionality and user experience.

When I'm not coding, I'm exploring new technologies, improving my problem-solving skills, contributing to personal projects and keeping up with web development. My goal is to create useful solutions while continuing to grow as a software engineer.

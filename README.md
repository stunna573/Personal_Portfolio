# Kelvin Gordian — Portfolio (Enhanced)

A responsive, single-page developer portfolio built with HTML, CSS and vanilla JavaScript.

## Run locally

1. Extract the project folder.
2. Open `index.html` in a browser, or use the Live Server extension in Visual Studio Code.

## Files

- `index.html` — page content and structure
- `index.css` — layout, responsive styles and light/dark themes
- `script.js` — mobile navigation, theme toggle, reading progress, animated introduction, scroll reveal and contact form behavior
- `assets/` — portrait and project preview images

## Notes

- Dark mode is the default. The theme toggle switches between dark and light mode and attempts to remember the visitor's choice in browser storage.
- Project preview links open the supplied screenshots. Live project and source-code URLs were not included in the original folder, so none have been invented.
- The contact form prepares an email using the visitor's default email application. It does not send messages through a server. A form service or backend is needed for direct website submissions.
- The original `.git` directory has been retained in the ZIP.


## Additional enhancements

- Retains the original `kelv.` logo, original teal/dark palette and original projects section.
- Refreshed introduction copy and animated portrait presentation.
- Floating labels, orbit motion, ambient glow and subtle status indicator animation.
- Reading progress indicator and animated role cursor.
- Light/dark theme toggle and responsive navigation remain available.
- Continuous motion is disabled when the visitor requests reduced motion.
